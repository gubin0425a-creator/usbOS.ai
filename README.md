## 🌟 핵심 특징 (Key Highlights)

- 🪟 **VirtualBox 설치 0회**: 윈도우 프로그램처럼 더블 클릭 한 번으로 독립 창 모드 1초 실행
- 💾 **실시간 데이터 영구 보존 (Persistent Vault)**: 대화 내역, API 키, 설정을 안전한 암호화 볼륨에 100% 자동 저장
- ⚡ **1초 윈도우 복귀**: 가상머신에 갇히지 않고 [절전] 버튼으로 현재 작업을 보존한 채 즉시 윈도우 바탕화면 복귀
- 🌍 **8개국어 & 컬러 이모지**: 한국어, 영어, 일본어, 중국어 등 8개 언어와 Unicode 15+ 컬러 이모지(⚡🧇🔥💎) 완벽 렌더링
- 🤖 **무제한 AI 확장**: OpenAI, Gemini, Claude부터 DeepSeek, Groq, 로컬 무료 Ollama까지 자유롭게 연동
- ⚙️ **C & NASM 32비트 진단 코어**: CPUID 하드웨어 정보와 컴파일러를 베어메탈 레이어에서 실시간 측정
- 🛡️ **군사 등급 데이터 보안**: 보이지 않는 글자(Zero-Width) 은닉 암호화 및 Argon2id + AES-256-GCM 2중 보호

## 📥 다운로드 및 시작하기 (Quick Start)

### 1. 공식 웹사이트
🌐 **[https://gubin0425a-creator.github.io/usbOS.ai/](https://gubin0425a-creator.github.io/usbOS.ai/)**

### 2. 실행 방법
1. 릴리즈 페이지에서 `usbOS-v1.0-amd64.iso` 다운로드
2. 저장소의 `usbOS-Launcher.bat` 파일과 같은 폴더에 넣고 더블 클릭!
3. 또는 **Rufus / Ventoy**를 이용해 USB에 구워 실물 PC에서 최고 성능으로 부팅 가능
